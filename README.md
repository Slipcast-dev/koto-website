# Koto — сайт приложения

Адаптивный сайт нативного переводчика Koto от **Slipcast-Dev**, реализованный по предоставленным HTML-макету, ТЗ и промпту.

- Сайт: https://slipcast-dev.github.io/koto-website/
- Репозиторий сайта: https://github.com/Slipcast-dev/koto-website
- Исходники приложения: https://github.com/Slipcast-dev/translator-Koto

## Архитектура и технологии

Статический HTML/CSS без JavaScript, серверного приложения, npm и внешних CDN. Системные шрифты, оригинальная эмблема, локальный CSS. Страница полностью работает без выполнения скриптов, не собирает тексты и не содержит аналитики. GitHub Pages обслуживает готовые файлы из корня ветки `main`.

Интерфейс переводчика — **фиксированная демонстрация**, а не онлайн-переводчик. Apple Translation, Qwen, OCR и горячие клавиши относятся к установленному приложению macOS. Декоративные элементы демонстрации не принимают ввод и не выполняют перевод.

## Запуск

Готовый `index.html` можно открыть двойным щелчком. Установка зависимостей не нужна.

Для просмотра через локальный сервер из папки проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://localhost:8765/. Остановить сервер: `Ctrl+C`.

## Настройка и сборка

Для изменения версии, платформы, года и адресов редактируйте **product.json**. Для изменения текста и разметки — **src/index.template.html**; для оформления — **assets/styles.css**. После изменения конфигурации или шаблона:

```sh
python3 scripts/build.py
```

Скрипт требует Python 3.10+ и использует только стандартную библиотеку. Он проверяет HTTPS-адреса, экранирует значения HTML и завершает сборку ошибкой при отсутствии обязательных данных. Страница, robots.txt и sitemap.xml генерируются в корне. Готовые файлы хранятся в Git, поэтому хостингу Python не нужен.

Переменные окружения, API-ключи, секреты, браузерное хранилище и cookie не используются. При переносе на другой адрес обновите `site_url` с завершающим `/` и пересоберите страницу.

## Публикация и обновление

GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Для публичного репозитория GitHub Pages предоставляет HTTPS-адрес без отдельного сервера.

После редактирования и сборки отправьте изменения в `main`; GitHub Pages автоматически повторно опубликует сайт. Следите за результатом в Actions и Settings → Pages. Не добавляйте в публичный репозиторий токены, `.env`, персональные данные или веса моделей.

## Достоверность и ограничения

28 октября 2026 сверены README, STATUS, INSTALLATION, PRIVACY, MODELS, LICENSE и список релизов приложения. Текущий prerelease: **0.1.0-alpha.14**, Chrome **0.1.4**. Обычный `/releases/latest` не возвращает alpha-релизы, поэтому кнопки скачивания используют прямые адреса файлов конкретного выпуска: `links.download` для установщика DMG и `links.extension_download` для ZIP расширения Chrome. Ссылка «Релизы» ведёт на общий список выпусков.

Требования: Apple Silicon и macOS 26+. Alpha имеет ad hoc подпись без Apple notarization. Документация продукта сохраняет ограничения интерактивной приёмки macOS 26, Live и внешних интеграций. Разработка сайта не является тестированием самого приложения.

Сайт не включает установщик приложения: скачивание выполняется из репозитория продукта. Для нового выпуска сначала проверьте релизы и документацию, затем обновите `version`, `links.download` и `links.extension_download` в `product.json` адресами `browser_download_url` соответствующих файлов из GitHub Releases и выполните `python3 scripts/build.py`. Закоммитьте конфигурацию вместе с готовым `index.html`: адреса файлов закреплены за указанным выпуском и автоматически не обновляются.
