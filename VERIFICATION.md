# Проверка сайта

Дата обновления: 30 октября 2026.

## Подтверждённые источники

Через GitHub API прочитаны дерево и исходники сайта, список релизов приложения, README.en.md, INSTALLATION.en.md и PRIVACY.en.md. Подтверждены опубликованный alpha.14, файлы DMG и Chrome 0.1.4 ZIP, а также наличие английских документов установки, моделей и приватности. Исходная эмблема Koto сохранена. Контрольные суммы и работоспособность приложения в этой задаче не проверялись.

## Выполненные проверки

- Реальная функция сборки выполнена с файловой системой в памяти, без клонирования репозитория и записи его файлов на компьютер.
- Пять Python-тестов: обе страницы и их метаданные/ресурсы/SVG/прямые ссылки; отказ при несовпадении ключей перевода; отказ при ссылке на страницу вместо установщика; экранирование переводов; отказ при пустом переводе.
- JavaScript выполнен в Node.js в изолированных контекстах: русский и региональные варианты, прочие языки, отсутствие языка, сохранённый выбор, явный параметр URL, некорректные значения, запрет localStorage, переходы в обе стороны, сохранение параметров и якоря.
- Сгенерированы русский и английский HTML, robots.txt и sitemap.xml. Наличие установщика и ZIP подтверждено метаданными GitHub Releases.
- Основная кнопка скачивания сохранена; в шапке только переключатель языка и ссылка GitHub. Иконки карточек и приватности заменены встроенными SVG.

Тесты хранятся в `tests/test_build.py` и `tests/language.test.cjs`. Команды запуска приведены в README. Локальное выполнение использовало исходники, переданные в память; обычный запуск из checkout и браузерная приёмка — отдельные проверки.

## Границы проверки

Новая версия не проходила визуальную проверку в реальном браузере, проверку скачивания кликом или запуск приложения. Не подтверждены отсутствие переполнения на всех размерах, отсутствие ошибок браузерной консоли и фактические языковые настройки ОС. Выполненные тесты используют модель браузерного окружения Node.js.

Перед следующей визуальной приёмкой проверьте ru/en на 360, 390, 768, 1024 и 1440 px; переходы переключателя при русском и нерусском основном языке браузера, отключённый JavaScript, запрещённое хранилище, клавиатурный фокус, изображения и реальные загрузки.
