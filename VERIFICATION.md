# Проверка сайта

Дата: 28 октября 2026.

## Источники и состав

Прочитаны НАЧАТЬ-ЗДЕСЬ.md, ПРОМТ.md, ТЗ.md и полный koto-mockup.html из родительской папки. Просмотрен koto-mockup.jpg. Основной источник композиции — HTML-макет. Эмблема скопирована без изменений.

Проверены через GitHub API: README, STATUS, INSTALLATION, PRIVACY, MODELS, LICENSE и последние prerelease-релизы. Подтверждены alpha.14 и наличие DMG, Chrome ZIP и контрольных сумм. Это проверка источников для сайта, не независимое тестирование функций приложения.

## Проверка в браузере

Использован встроенный браузер Codex, локальный сервер Python, DOM-инспекция и полноразмерные снимки. Проверены 360, 390, 768, 1024 и 1440 px. На этих размерах ширина документа не превышает viewport, обе эмблемы загружены, на телефоне панели и карточки расположены последовательно, на десктопе — в две и три колонки соответственно.

Переход по «Возможности» проверен кликом: открывает #features. Консоль проверенной страницы не содержит ошибок и предупреждений. Ссылки установки, приватности, моделей и лицензии соответствуют доступным документам GitHub; скачивание ведёт на существующий список релизов. Навигация — стандартные ссылки, добавлены видимый :focus-visible и ссылка пропуска шапки. Горячие клавиши приложения не перехватываются. Скриптов сайта и сторонних запросов ресурсов нет.

Снимки: screenshots/mobile-390.png и screenshots/desktop-1440.png.
